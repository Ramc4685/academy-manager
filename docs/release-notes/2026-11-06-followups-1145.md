# followups-1145

PR: #1155

## What changed
- Parent Children page: an ended enrollment now shows the day it actually ended. Withdrawals store the admin-picked day as midnight UTC, and the page used to shift that into Chicago time, so "Ended" read one day early. The new `formatAcademyDay` helper reads a midnight-UTC value as that calendar day, the same way the admin past-enrollments table already did, and still formats real instants (removals) in the academy timezone.
- Dev/staging reseed: `run_all_migrations` drops secondary indexes before replaying, so `scripts/local_test_stack.sh seed` and the SaaS staging seed now work on a database that was already migrated. Before, 17 migrations whose indexes a later migration redefines failed on replay with Mongo index conflicts. A new real-Mongo contract test replays twice and checks the index set matches a fresh replay.
- Pre-push gate: each run writes check output to its own temp file, so concurrent gates in other worktrees no longer overwrite each other's failure output.

## Deploy notes
Frontend change ships with the next deploy. No migration and no data change. `run_all_migrations` is not used at production boot (that is `run_pending_migrations`).

## Risk / rollback
Low. The replay now rebuilds indexes on the target DB, which briefly leaves a staging DB unindexed during a reseed; documents and validators are untouched. Roll back by reverting the PR.
