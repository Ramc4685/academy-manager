# release

PR: #319

## What changed
Self-service policy moved into Settings. It is now the "Self-service" tab of
`/admin/settings` (`?panel=self-service`) instead of a separate top-level nav
item, matching the other settings panels. The old `/admin/settings/self-service`
URL now redirects into the panel, so existing bookmarks keep working. This also
removes the duplicate nav item that previously double-highlighted Settings.

## Deploy notes
No migration detected in the diff. Frontend-only; the `self-service-policy` API
is unchanged. No env var or manual step needed.

## Risk / rollback
Low risk — the settings shell was built for exactly this and the form code moved
as-is (query keys, testids, and error markup preserved). If the redirect or panel
regresses, revert the merge commit; the old route file and nav item come back
with it.
