# hold-lifecycle-followups

PR: #705

## What changed

Closes four defects found in a post-merge review of the enrollment-hold feature (#701): a self-cancel silently discarded across a hold, seat-reserving paths (registration approval, `ConfirmEnrollment`) bypassing the hold-reclaim broker, a crashed reclaim misrecorded as a completed hand-over instead of an orphan, and held months writing no billing deferral. Also corrects two problems a second review found in the first-pass fix for those four: `ReturnFromHold` now closes its `BillingDeferral` (mirroring `ResumeEnrollment`'s close-on-resume), and the coach roster-add path (`CoachAddStudentToRoster`) is now brokered like the admin path, with the structural wiring test widened to scan all of `backend/v2` instead of only top-level `composition/*.py`.

## Deploy notes

No migration. Builds on #701/#702; no new env vars or manual steps.

## Risk / rollback

Billing-deferral close-on-return and the coach seat-broker fix change hold/return and roster-add money-adjacent paths; both are covered by the full backend suite (4609 passed) plus the widened structural test. Revert the merge commit if this regresses.
