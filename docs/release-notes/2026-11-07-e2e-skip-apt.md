# e2e-skip-apt

PR: #1158

## What changed
- CI: the Chromium e2e jobs (both mobile shards, Desktop, Real Auth, and the nightly accessibility job) no longer run `playwright install-deps` on every job. The runner image already has every shared library Chromium needs; install-deps was only adding nine font packages, and on a slow Azure apt mirror that took 10 to 11 minutes and cancelled the 12-minute shard with no test failing (PR #1153 run 42235161242, PR #1155). The browser is now installed first, `ldd` checks its binaries, and apt runs only if a library is actually missing, under a 5-minute step timeout. No e2e test compares screenshots, so the skipped fonts change nothing.

## Deploy notes
CI only. No app, migration, or data change.

## Risk / rollback
Low. If a future runner image drops a Chromium library, the probe sees it and falls back to the old install-deps path. Roll back by reverting the PR.
