# Generated Architecture Documentation

Code-grounded architecture of **CourtMastr Academy Manager**, generated by static
inspection of the repository (no application code was modified). Every diagram cites the
source files it was derived from. Confirmed facts are separated from assumptions and
gaps in each document.

- **Stack (confirmed):** Next.js 15 / React 19 (Cloudflare Worker) · FastAPI v2 (Fly.io) · MongoDB (Atlas) · Firebase Auth · Stripe · Resend · APScheduler (in-process).
- **Architecture style:** Clean-Architecture-Lite monolith with DDD bounded contexts and per-persona BFF interfaces. SaaS multi-tenant code exists but production runs single-academy mode.
- **Generated:** 2026-06-21.
