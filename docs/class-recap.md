# Class recaps

Open a dated class after it starts to record what the group actually learned.

- **Assigned lead coach:** Open the session from Coach Today and expand **Class recap**. Add the skills you taught. When everyone participated, choose **Credit everyone present** for one skill or the full lesson. Adjust individual drills for children who sat out. Present and late marks count. Save once for the class. You can include a skill from another level without changing the child's level.
- **Owner:** Open the class date in the admin session details to enter a verbal report yourself. The dashboard also lists private reports waiting for you. Open the report, update the recap, and mark the handoff handled.
- **After-class report:** Enter the coach's words in the class recap. Send them to the owner, or opt into AI processing if it is enabled for this academy. Say what was taught, who practiced each skill, and who sat out. An explicit group practice statement can credit confirmed attendees. A teaching-only statement records the group lesson. A clear AI reading adds facts to the existing record. Ambiguity requires clarification, and a correction can be made in the class form.
- **Parent:** Open **Progress** and select your child. Recent class recaps show the group's lesson, that child's practice, and which of those skills the child has passed as of today. The class date tells you when the lesson took place. Record formal passes through the existing skill assessment flow, which enforces the skill's pass rules.

The owner and the reporting coach can read the private report. Families see structured skill names. The optional AI path sends the entered report to the academy's configured provider after substituting roster names and masking emails and phone numbers. Keep private details unrelated to the class out of the report.

One recap belongs to one dated class. Direct edits check its revision and start time so concurrent edits and rescheduled classes can be reviewed before saving. A retry with the same mutation ID is safe. The family recap is available in the app.
