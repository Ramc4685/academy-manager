## backend/v2/README.md

The README does not mention billing, autopay, dunning, webhooks, dashboards, readiness DTOs or timezones, so the uncommitted billing changes (ledger refund repair, late-return webhook handling, `bank_return_review` attention kind, `bank_returns_to_review` alert count, `fees_collector`/`losses_collector` removal, `academy_timezone` on `HandleWebhookEvent`) add no drift of their own. Items 1-12 were re-verified on 2026-11-15 and still hold.

1. [stale-not-built] README:3 links `../../../.claude/plans/write-a-detailed-plan-curried-trinket.md`. That path resolves outside the repo and does not exist in the worktree (`.claude/plans` is absent). The plan lives only in the user's home directory.
2. [contract] README:27 says `contract/` is "mongo + stripe via testcontainers". No `testcontainers` reference exists under `backend/` or in the requirements files. CI runs the contract tier against a native mongod (`.github/workflows/production.yml:167`, job `backend-contract-real-mongo`). Stripe fixtures are static (`backend/v2/tests/contract/stripe_fixtures`). Contract tests use the `real_db` fixture (`backend/v2/tests/contract/conftest.py:146`), a throwaway database on a real mongod.
3. [contract] README:42 says ADR-0005 has "six layer rules" enforced by import-linter (README:33). `backend/pyproject.toml:84-182` has six contracts (domain-is-pure, application-does-not-import-infrastructure, infrastructure-does-not-import-interfaces, interfaces-do-not-import-infrastructure-or-domain-directly, invoicing-core-independent-of-academy-pricing, composition-is-outermost), but the ADR's no-cross-context and tenancy-literal rules are not import-linter contracts. Tenancy literals are a pytest check (`backend/pyproject.toml:190-192`, `backend/v2/tests/structural`, `backend/v2/tests/test_no_raw_tenant_mongo_access.py`).
4. [contract] README:101 says mypy is `mypy --config-file backend/pyproject.toml v2` and "advisory". CI runs `mypy --config-file backend/pyproject.toml -p backend.v2` from the repo root, filtered against `backend/mypy-baseline.txt`. It blocks on new errors (`production.yml:268-274`).
5. [contract] README:103 says `pytest v2/tests` with "≥70% coverage on `v2/shared`". CI enforces `--cov=v2 --cov-fail-under=86` on all of v2 (`production.yml:165`).
