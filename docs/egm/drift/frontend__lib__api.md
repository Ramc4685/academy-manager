## frontend/lib/api/README.md

- [stale-not-built] README:13-14 says `generated/` "currently contains only `.gitkeep`" and no generated `v2.d.ts` is committed. Code: `frontend/lib/api/generated/v2.d.ts` is tracked and there is no `.gitkeep`.
- [stale-not-built] README:30-31 says "When generated types are reintroduced, commit the resulting `generated/v2.d.ts`". They are already present and committed (`frontend/lib/api/generated/v2.d.ts`).
- [stale-not-built] README:35-39 says CI only checks drift when `openapi.snapshot.json` exists, that the snapshot is not committed, and that CI prints "No openapi.snapshot.json yet. Skipping drift check." Code: `frontend/lib/api/openapi.snapshot.json` is tracked, and `.github/workflows/production.yml:312-320` runs the check unconditionally with no skip message. It regenerates types from the snapshot and diffs them against `lib/api/generated/v2.d.ts`.
- [contract] README:16-28 says types are regenerated from the running FastAPI app (uvicorn on port 8001, then `pnpm generate:api`). Code: `frontend/package.json:16` defines `generate:api` as `openapi-typescript lib/api/openapi.snapshot.json -o lib/api/generated/v2.d.ts`. It reads the committed snapshot, needs no running server, and does not refresh the snapshot. The README does not say how the snapshot itself is updated. `production.yml:313` says a backend structural test keeps the snapshot equal to the live API.
- [undocumented] README:7-10 lists only `client.ts`, `admin.ts`, `admin-teaching.ts`, `coach.ts`, `curriculum.ts`, `me.ts`, `parent.ts` and `registration.ts`. Many other modules in `frontend/lib/api/` are not mentioned: `admin-account-deletions.ts`, `admin-ai-import.ts`, `admin-crm-pipeline.ts`, `admin-families.ts`, `admin-family-contacts.ts`, `admin-family-crm.ts`, `admin-family-import.ts`, `admin-people-duplicates.ts`, `auth-bridge-cookie.ts`, `auth-token.ts`, `billing-contract.ts`, `coach-paths.ts`, `magic-link.ts`, `parent-home.ts`, `password-reset.ts`, `payment-error.ts`, `platform.ts`, `proxy-headers.ts`, `proxy-origin.ts`, `student.ts` and `unsubscribe.ts`. The `*.node-test.mjs` and `*.test.ts` test files are also unmentioned.
- [undocumented] README:5-14 does not mention the committed `openapi.snapshot.json` (about 1.4 MB). The CI check and `generate:api` both depend on it.
- [wording] README:9-10 calls `admin.ts` and the other modules "thin" wrappers. `frontend/lib/api/admin.ts` is about 136 KB, so "thin" is misleading.
- [undocumented] README:7 does not mention that `client.ts` also exports a `timeoutMs` option, defaulting to 20s (`client.ts:168,172`). It describes dedup only as "in-flight dedup". Dedup is on by default for readable (GET) requests and can be turned on for other methods with `dedup` (`client.ts:193-196`).
