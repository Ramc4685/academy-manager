## README.md (repo root)

- [wording] README line 28: Coach Payouts are described as "Per-session rates, hours worked, automated payout statements". Code supports three rate units, `per_session`, `per_hour` and `percent_of_revenue` (`backend/v2/contexts/coaching/domain/payout.py:27`). Payouts are generated and approved as payout periods (`backend/v2/contexts/finance/domain/payout_period.py`, `backend/v2/contexts/finance/application/use_cases/approve_payout_period.py`). The README omits the percent-of-revenue unit and the period approval workflow, and "automated payout statements" is not a named artifact in the code.
- [wording] README line 173: scripts/ is described as holding "importers". `scripts/` contains no importer scripts. It has seed, backfill, audit, release and staging tools under `scripts/dev` (for example `scripts/dev/seed_blno_staging.py`, `scripts/dev/backfill_student_pathway_placements.py`), plus `scripts/ci`, `scripts/ops`, `scripts/prod` and `scripts/smoke`.
